# CodeAlpha Task 3 - JPG File Automation

## Description
This project is a Python automation script that moves all `.jpg` files from a source folder to a destination folder.

## Technologies Used
- Python
- os module
- shutil module

## How It Works
1. The script checks the source folder.
2. It finds all JPG files.
3. It moves the JPG files to the destination folder.
4. It displays the moved files.
